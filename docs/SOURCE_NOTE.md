# Source Note

Public reference dataset:
https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

The public Kaggle listing describes the IBM HR Analytics Employee Attrition & Performance dataset as a **fictional dataset created by IBM data scientists**, with 1,470 records and 35 columns.

For this portfolio project, the original downloadable file was not programmatically retrieved in this environment. To avoid misrepresenting generated rows as the original source data, this repository bundles a deterministic synthetic portfolio extract using the documented field structure and analytical concepts.

The source is used as the schema/reference basis, not as a claim that the bundled rows are the original IBM records.
